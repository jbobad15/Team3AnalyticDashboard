# Team 3 — SCE Transmission Planning Analytics Dashboard

A Streamlit analytics dashboard for findings normalized by Team 2 and extracted by Team 1. It supports filters, findings tables, charts, recurrence and persistence ranking, baseline/sensitivity comparisons, and cross-report comparisons.

## Run

py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py

 running on http://localhost:8501

This is just testing phase, using built in samples.
